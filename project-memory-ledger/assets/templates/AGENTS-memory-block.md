## 项目记忆协议

- 对较重要的任务，读取存在的 `memory.md` 和 `memory/INDEX.md`；只在相关时再查阅详细记忆和原始证据。
- 将 `AGENTS.md` 作为简洁的高注意力规则层。把有用但无需每次强提醒的经验放入 `memory.md`；将会话历史和追加式记忆账本放进 `memory/`。
- 保存会话时，只归档当前可访问的用户可见消息和可用工具交互。不完整的记录标记为 `partial` 或 `summary_only`；不得记录秘密、隐藏提示词或私有思维链。
- 每条重要记忆都要有稳定的 `MEM-*` ID 和可追溯来源。`memory/ledger.jsonl` 只追加；通过新事件修改、晋升、拒绝或取代旧记录。
- 不得把假设当作事实晋升。根据当前源码、测试、已批准决策或维护者明确指示验证主张，并明确处理冲突。
- 只有稳定、高影响、值得持续强提醒的规则才晋升到本文件。反复有用的经验进入根目录 `memory.md`。避免在不同文件重复整段说明。
- 不得保存凭据；不得自动提交、推送、外传或破坏性清理记忆文件。
